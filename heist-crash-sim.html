Arcade physics demo for research / game-feel study. Uses virtual demo points with no monetary value — no deposits, withdrawals, payments or real-money mechanics of any kind. Crew members are simulated bots.
Bust multipliers use a commit-reveal provably-fair scheme (SHA-256) you can audit via 🛡 — or in the console via window.__vault.

🛡 Provably Fair

Before each job, a random server seed is generated and its SHA-256 hash is shown on screen — a commitment made before any points are staked. The bust point is then derived as SHA-256(serverSeed : clientSeed : nonce), mapped through the public RTP formula. After the job, the server seed is revealed so you can recompute everything and confirm the commitment matches — the outcome provably couldn't have been changed after you joined.
client seed
Your client seed is mixed into every outcome. Change it any time — it applies from the next job.
Demo-grade entropy (crypto.getRandomValues) — a production system would use an audited server-side CSPRNG. Verify recomputes both the commitment hash and the bust point from the revealed seed, entirely in this page.
