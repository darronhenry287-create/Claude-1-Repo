# WARCAT — logo files

Vector-exact rasterizations of the WARCAT logo used in the storefront theme. Each comes as a
scalable **`.svg`** (use this wherever you can — it never blurs) and a high-res transparent **`.png`**.

| File | Use it for |
|------|------------|
| `warcat-logo-mark.png` (1024×1024) | App icon, favicon, social avatar, profile picture — the teal cat tile on its own |
| `warcat-logo-horizontal.png` | Primary logo on light backgrounds — site header, invoices, email |
| `warcat-logo-horizontal-white.png` | Same lockup on **dark** backgrounds (the mark stays teal, the word goes white) |
| `warcat-logo-stacked.png` | When you need a square-ish footprint — packaging, stamps, centered layouts |

All PNGs have a **transparent background**, so they drop onto any color.

## Colors

| Role | Hex |
|------|-----|
| Brand teal (the tile) | `#0fb5a6` |
| Cat features (face on the tile) | `#04332e` |
| Wordmark ink (on light) | `#0e1a26` |
| Wordmark on dark | `#ffffff` |

Typeface: **Space Grotesk** (Bold, −3% letter-spacing) — converted to outlines, so no font is needed to display it.

## Quick rules

- Keep clear space around the logo of at least the height of the cat tile.
- Don't recolor the tile, stretch the lockup, or add effects/shadows.
- On busy photos, use the all-teal mark or place the lockup on a solid bar.
- Minimum size: keep the wordmark legible — about 24px tall on screen, 8mm in print.
