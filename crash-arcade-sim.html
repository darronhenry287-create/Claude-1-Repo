Arcade physics demo for research / game-feel study. Uses virtual demo points with no monetary value — no deposits, withdrawals, payments or real-money mechanics of any kind. Other "players" are simulated bots.
Crash multipliers use a commit-reveal provably-fair scheme (SHA-256) you can audit via 🛡 — or in the console via window.__ascent.

🛡 Provably Fair

Before each round, a random server seed is generated and its SHA-256 hash is shown on screen — a commitment made before any points are locked. The crash point is then derived as SHA-256(serverSeed : clientSeed : nonce), mapped through the public RTP formula. After the round, the server seed is revealed so you can recompute everything and confirm the commitment matches — the outcome provably couldn't have been changed after you bet.
client seed
Your client seed is mixed into every outcome. Change it any time — it applies from the next round.
Demo-grade entropy (crypto.getRandomValues) — a production system would use an audited server-side CSPRNG. Verify recomputes both the commitment hash and the crash point from the revealed seed, entirely in this page.
