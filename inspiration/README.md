# 📥 Inspiration drop-zone

Drop any reference templates / themes / design files here for Claude to study.

**How to use:**
1. Add your files into this `inspiration/` folder (subfolders are fine — e.g.
   `inspiration/template-1/`, `inspiration/template-2/`).
2. Commit & push them to a branch I can see (this session's branch
   `claude/laughing-archimedes-4hg4V` is perfect, or tell me which branch).
3. Tell me they're up — I'll `git fetch` and read every file.

**What's most useful:**
- Full HTML/CSS theme files, ZIPs, or Shopify themes → I can read the code directly.
- Screenshots / images of designs you like → drop the image files here, or just
  attach them straight into the chat (paperclip / drag-and-drop in the composer).

These are **inspiration only** — store #3 (AEON) stays deliberately distinct from
your other two stores. I'll borrow layout ideas, section patterns, and polish,
not the look wholesale.
